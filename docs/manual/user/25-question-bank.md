# 25장 질문 예시 모음

이 장은 예제 데이터에 **실제로 물어본 질문과 그 결과**를 모은 것입니다. 질문을 어떻게 써야 할지 막힐 때,
비슷한 질문을 찾아 그대로 또는 조금 바꿔 물어보세요. 표의 칸은 다음 뜻입니다.

| 칸 | 뜻 |
| --- | --- |
| 질문 | 채팅 칸에 입력한 글 그대로 |
| 조회 조건 | 챗봇이 질문을 이해한 내용(프로그램이 실제 조회한 조건). 내 뜻과 같은지 확인하는 칸 |
| 결과 | 정상 ①②③ / 결과 0건 / 조회 실패(이유) / 질의 아님 / Action 미리보기 |
| 답 | 화면에 나온 답(길면 앞부분만). AI 가 쓰므로 다시 물으면 문장이 조금 다를 수 있습니다 |

> **주의** 결과가 "정상 ①"이어도 조회 조건이 내 질문과 다르면 답도 내 뜻과 다릅니다. 표에서도 그런 줄이
> 몇 개 있습니다(각 분류 끝의 "살펴볼 점"에 적었습니다). 이것이 조회 조건을 먼저 확인해야 하는 이유입니다.

> **알아 두기** 이 표는 22장까지의 실습을 마친 뒤의 데이터로 물었습니다. 그래서 일부 값이 앞 장과 다릅니다
> (예: 수원 변전소 04호의 위험등급이 원천 동기화로 2가 되어 "위험등급 1인 시설"이 6곳). 또 9번 문항
> "위험등급이 5인 전주는 몇 개야?"는 6장 촬영 때 **철탑** 으로 잘못 이해했던 질문인데, 이번에는 **전주** 로 맞게
> 이해했습니다. 같은 질문이라도 매번 같게 이해한다는 보장이 없으므로, **매번** 조회 조건을 확인해야 합니다.

  맞는 문장을 만들지 못해 본문 대신 안내가 나온 경우입니다. 조회 조건이 맞으므로 "조직은 몇 개야?"처럼 짧게 다시
  물으면 대개 답이 나옵니다.
- 나머지는 조회 조건이 모두 질문과 맞습니다.
