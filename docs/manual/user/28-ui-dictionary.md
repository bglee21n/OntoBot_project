# 28장 화면 문구 사전

화면에서 처음 보는 단추나 안내 문구가 무슨 뜻인지 찾아보는 장입니다. 화면별로 나누었고, 화면에 보이는
글자 그대로 적었습니다.

## 28.1 모든 화면 공통

| 화면 문구 | 뜻 · 할 일 |
| --- | --- |
| **OntoBot** (왼쪽 위) | 프로그램 이름. 누르는 단추는 아닙니다 |
| **채팅** | 질문하는 화면으로 갑니다 |
| **인터뷰** | 인터뷰 워크숍 화면. 현업 전문가·모델러에게만 보입니다 |
| **온톨로지** | 데이터 설계도 화면 |
| **평가** | 챗봇 시험 화면. 챗봇 빌더·모델러에게만 보입니다 |
| **데이터 소스** | 데이터 연결·동기화 화면 |
| **Action** (옆 빨간 숫자) | 데이터 변경 요청·승인 화면. 빨간 숫자는 읽지 않은 알림 수 |
| **관리** | 사용자·권한 관리 화면. 관리자에게만 보입니다 |
| 김사용 · user | 내 이름 · 내 역할 |
| **로그아웃** | 로그인을 끝냅니다 |
| 불러오는 중… | 서버에서 내용을 가져오는 중입니다. 계속 이 글자만 보이면 내 역할로 볼 수 없는 화면일 수 있습니다 |
| 이 화면을 볼 권한이 없습니다 | 내 역할로는 쓸 수 없는 화면입니다 |
| 저장 / 추가 / 취소 / 삭제 | 입력한 내용을 저장 / 새로 넣기 / 그만두기 / 지우기 |
| 삭제할까요? | 지우기 전에 한 번 더 묻는 창. **확인** 을 누르면 지웁니다 |

## 28.2 로그인 화면

| 화면 문구 | 뜻 · 할 일 |
| --- | --- |
| 아이디 / 비밀번호 | 관리자에게 받은 아이디와 비밀번호를 입력하는 칸 |
| **로그인** | 아이디·비밀번호를 확인합니다. 확인하는 동안 "확인 중…"으로 바뀝니다 |
| **SSO 로 로그인** | 회사 통합 계정으로 로그인합니다(설정한 회사만 보임) |
| 아이디 또는 비밀번호가 올바르지 않습니다 | 둘 중 하나가 틀렸습니다. Caps Lock·한/영 전환을 확인하세요 |
| SSO 로그인에 실패했습니다… | 회사 통합 로그인이 실패했습니다. 다시 시도하거나 관리자에게 문의 |

## 28.3 채팅(질의) 화면

| 화면 문구 | 뜻 · 할 일 |
| --- | --- |
| **새 대화** | 새 주제로 대화를 시작합니다. 앞 대화의 "그 중" 맥락이 섞이지 않습니다 |
| 아직 대화가 없습니다. | 처음 쓰는 사람의 대화 목록 |
| 질의 | 채팅 화면의 제목 |
| 등록된 데이터에 대해 물어보세요… | 첫 화면 안내 |
| 예: 위험등급이 3 이상인 시설은 몇 개야? | 입력 칸의 예시 글(입력하면 사라짐) |
| **보내기** | 질문을 보냅니다. **Enter** 와 같습니다. 줄 바꿈은 **Shift + Enter** |
| 답을 만드는 중… | 답이 끝날 때까지 다른 질문을 보낼 수 없습니다 |
| 질문을 조회 조건으로 바꾸는 중… | 진행 1단계: AI 가 조회 계획을 세우는 중 |
| 조회하는 중… | 진행 2단계: 데이터를 찾는 중 |
| 답을 쓰는 중… | 진행 3단계: AI 가 답 문장을 쓰는 중 |
| 근거를 대조하는 중… | 진행 4단계: 답과 데이터를 대조하는 중 |
| 조회 조건: … | 챗봇이 질문을 이해한 내용. **가장 먼저 확인할 곳** |
| 관계 정보는 ○○ 기준입니다(그래프 반영 지연). | 관계(소유 조직 등) 정보가 그 시각 이후 아직 반영되지 않음 |
| **① 근거 확인** | 답의 사실 문장이 모두 조회 결과와 글자 그대로 맞음 |
| **② 일부 추정** | 근거를 못 찾은 문장이 있음. 그 문장 앞에 **추정** 표시 |
| **③ 근거 부족** | 근거와 맞는 답을 만들지 못해 본문을 보여 주지 않음 |
| 추정 | 그 문장은 데이터에서 글자 그대로 확인하지 못했다는 표시 |
| 근거 칩(예: 강남 변전소 01호, 결과 1) | 답이 기댄 데이터. 누르면 근거 카드가 열림. "결과 N"은 집계 결과 |
| 결과 0건 — 조회 조건(…)에 맞는 객체가 없습니다. | 조회는 성공, 조건에 맞는 데이터가 없음 |
| ⚠ 조회 실패 · 질문 해석 실패 | 질문을 조회 조건으로 바꾸지 못함 |
| ⚠ 조회 실패 · 권한 없음 | 볼 수 없는 데이터 |
| ⚠ 조회 실패 · 실행 오류 / 시간 초과 | 일시적인 시스템 문제 |
| ⚠ 조회 실패 · 관계 저장소 연결 불가 | 관계 정보를 쓸 수 없음. 관계 없는 질문은 됨 |
| ⚠ 조회 실패 · 결과 과다 | 조건에 맞는 대상이 너무 많음. 조건을 좁히세요 |
| ⚠ 조회 실패 · 답변 모델 연결 불가 | AI 모델이 응답하지 않음 |
| ⚠ 조회 실패 · 게시된 온톨로지 없음 | 설계도가 아직 게시되지 않음(설치 직후) |
| ⚠ 조회 실패 · 내부 오류 | 예상하지 못한 오류. 시각과 함께 관리자에게 알리세요 |
| 저는 등록된 데이터를 조회해 답합니다… | 인사·잡담은 데이터 질문이 아니라는 안내 |

### 근거 카드

| 화면 문구 | 뜻 |
| --- | --- |
| 근거 카드 / **닫기** | 근거 데이터의 상자 / 상자를 닫음 |
| 굵은 글씨의 값 | 답에 인용된 칸 |
| 마지막 동기화 | 그 값을 원래 시스템에서 마지막으로 가져온 시각. "기록 없음"이면 동기화 기록이 없음 |
| 값 출처: 데이터 소스 · 표 · 동기화 실행 #N (시각) | 그 값이 어느 시스템·어느 동기화에서 왔는지 |
| 값 출처: 원천 기록 없음(시드·직접 적재) | 동기화가 아니라 처음 설치 때 직접 넣은 데이터 |
| **편집됨** 원천 값 ○ · 이름 · 시각 | Action 으로 바꾼 값. 원래 값과 누가 언제 바꿨는지 |
| 원천이 바뀜: ○ (시각) — 편집 값이 우선합니다 | 바꾼 뒤 원래 시스템 값도 바뀜(편집 충돌). 빨간 글씨면 아직 처리 전 |
| 확인됨 | 모델러가 충돌을 확인함 |
| 결과 N — 집계·계산 결과입니다. 답을 만들 때 조회 조건으로 계산해 대조한 값이며, 지금 다시 계산한 값이 아닙니다. 조건은 답 위의 조회 조건을 보세요. | 개수·평균·비율 같은 계산 결과 — 객체 카드 대신 답을 만들 때의 계산 값을 보여 줌 |

| 화면 문구 | 뜻 · 할 일 |

## 28.4 Action 화면

| 화면 문구 | 뜻 · 할 일 |
| --- | --- |
| Action 은 미리보기 → 승인 → 실행 순서로 진행합니다… | 화면 안내 |
| Action 요청 | 화면에서 직접 요청하는 칸 |
| Action / 대상 객체 pk | 어떤 Action 을 / 어떤 대상(식별자)에 |
| 파라미터 이름 뒤의 * | 꼭 입력해야 하는 값 |
| **미리보기** | 요청을 만들고 무엇이 바뀌는지 보여 줌(아직 바뀌지 않음). 누르는 중에는 "확인하는 중…" |
| 요청할 수 있는 Action 이 없습니다. | 내 역할로 요청할 수 있는 Action 이 없음 |
| **승인 대기** / **내 요청** / **전체 기록** | 내가 승인할 요청 / 내가 한 요청 / 내가 볼 수 있는 모든 요청 |
| 기록이 없습니다. | 그 탭에 요청이 없음 |
| 바뀔 값 · 지금 · 실행 후 | 무엇이 어떤 값에서 어떤 값으로 바뀌는지 |
| 사전 조건 ✓ / ✗ | 실행해도 되는 상태인지 통과 / 실패 |
| 알림 · 앱 알림 · N명 | 누구에게 몇 명에게 어떤 문구가 가는지 |
| 되돌릴 수 없음 | 메일·SMS. 보내면 되돌릴 수 없음 |
| 실행할 수 없습니다 | 막힘. 아래에 이유가 적힘 |
| 주의 | 막지는 않지만 알아 둘 내용 |
| 승인을 기다립니다. | 승인자가 결정하기 전 |
| **승인하고 실행** | 승인과 동시에 실행. 메일·SMS 가 있으면 확인 창이 한 번 더 뜸 |
| 거부 사유(선택) / **거부** | 거부 이유를 적고 거부 |
| **요청 거두기** | 요청자가 승인 전에 취소 |
| **롤백** | 실행된 요청을 되돌림. 확인 창이 뜸 |
| 요청 ○ · 시각 / 결정 ○ · 시각 | 요청한 사람·시각 / 결정한 사람·시각 |
| 실패 사유 / 거부 사유 | 실행이 실패한 이유 / 거부한 이유. "요청자가 거뒀습니다"는 거둔 요청 |
| 발송 · 대기/보냄/실패/취소 | 알림 발송 상태 |
| 상태 배지: 승인 대기 · 막힘 · 거부 · 실행됨 · 실패 · 롤백됨 | 요청의 지금 상태 |
| 알림함 / **모두 읽음** | 받은 앱 알림 / 모두 읽음으로 표시(빨간 숫자가 사라짐) |
| 정정 | 롤백으로 무효가 된 알림을 알리는 알림 |
| 알림이 없습니다. | 받은 알림이 없음 |

## 28.5 인터뷰 화면

| 화면 문구 | 뜻 · 할 일 |
| --- | --- |
| 인터뷰 워크숍 | 화면 제목 |

| 진행 중 · 제출됨 · 게시됨 | 인터뷰 상태 |
| 역할 · 업무 흐름 · 의사결정 지점 · 사용 데이터 · 예외 상황 · 찾아보는 질문 | 인터뷰 주제 여섯 가지 |
| 대기 · 진행 중 · 완료 · 정보 부족 | 주제별 진행 상태 |
| 답을 입력하세요(Ctrl+Enter 로 보내기) / **보내기** | 답 입력 칸 |
| 답을 정리하는 중… | AI 가 답을 평가하고 후보를 뽑는 중 |
| 인터뷰를 마쳤습니다… | 모든 주제가 끝남. 오른쪽 목록을 검토할 차례 |
| 인터뷰 대상자만 답할 수 있습니다. | 인터뷰를 만든 사람만 답할 수 있음 |
| 제출된 인터뷰입니다… | 더 답할 수 없음 |
| 검토 목록 | 뽑힌 후보 |
| 객체 타입 · 속성 · 관계 · 조치(Action) 후보 · 자주 묻는 질문 | 후보 종류 |
| 검토 전 · 확정 · 수정 확정 · 거절 | 후보 상태 |
| 근거 발언 #N "…" | 그 후보가 나온 내 발언(N번째) |
| 발언에서 이 문장을 찾지 못했습니다… | 근거가 맞지 않음. 고치거나 거절 |
| 요소 내용이 올바르지 않습니다 | 후보 내용에 문제(예: 목록형인데 값이 없음). **수정** 으로 고침 |
| **확정** / **수정** → **수정 확정** / **거절** | 맞다 / 고쳐서 확정 / 필요 없다 |
| 답할 수 있는 질문이면 기대 답변을 적어야 확정됩니다. | 질문 후보는 기대 답변이 필요 |
| **검토 마치고 제출** | 모든 후보를 처리한 뒤 제출. 그 전에는 눌리지 않음 |
| **온톨로지 초안으로 게시** | (모델러) 확정 후보로 새 draft 를 만듦 |
| draft 버전(id N)을 만들었습니다. 평가셋 초안 질문 N개. / **draft 열기** | 초안이 만들어짐 / 그 초안으로 이동 |

## 28.6 온톨로지 화면

| 화면 문구 | 뜻 · 할 일 |
| --- | --- |
| 온톨로지 버전 | 버전 목록 |
| **빈 draft 만들기** | 빈 설계도에서 시작 |
| **이 버전으로 새 draft** | 그 버전을 복사해 고칠 수 있는 초안을 만듦 |
| draft · 게시됨 · 보관됨 | 작성 중 · 지금 쓰는 것 · 예전 것 |
| 게시·보관된 버전은 수정할 수 없습니다… | 고치려면 새 draft 를 만들 것 |
| 게시 전 검사 / 게시 전 검사를 모두 통과했습니다. | 문제 목록 / 문제 없음 |
| **게시** | draft 를 게시. 확인 창: "게시하면 현재 게시본은 보관되고…" |
| 내보내기: **YAML** · **JSON** | 설계도를 파일로 받기 |
| **임포트 (YAML/JSON)** / **임포트** | 파일 내용으로 draft 를 통째로 바꿈. 검사에 걸리면 아무것도 안 바뀜 |
| **버전 비교** · 기준 버전 · 추가/삭제/변경 | 다른 버전과 무엇이 달라졌는지 |
| 차이가 없습니다. | 두 버전이 같음 |
| 객체 타입 / 링크 타입 / 속성 | 설계도의 세 부분 |
