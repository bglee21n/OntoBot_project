# 23장 연습 문제

배운 것을 직접 해 보며 익히는 장입니다. 문제마다 **채팅에 무엇을 입력할지**, **조회 조건에서 무엇을 확인할지**를
스스로 정한 뒤, 장 끝의 풀이와 맞춰 보세요. 정답 숫자는 **예제 데이터를 처음 설치한 상태** 기준입니다(13장
이후의 실습으로 값이 바뀐 시설이 있으면 다를 수 있습니다 — 그 차이를 설명할 수 있으면 더 잘한 것입니다).

## 23.1 기초: 질문하고 조회 조건 읽기

**문제 1.** 대구 지역에 있는 철탑의 목록을 보세요. 몇 곳입니까?

**문제 2.** 수원지사가 소유한 변전소는 몇 개입니까? 조회 조건에서 확인해야 할 조건 두 가지는 무엇입니까?

**문제 3.** 2015년 이후에 설치된 위험등급 4 이상 철탑을 모두 찾으세요. 조회 조건에 조건이 몇 개 있어야 합니까?

**문제 4.** 전주의 평균 위험등급은 얼마입니까? 근거 칩은 무엇으로 보입니까?

**문제 5.** 위험등급이 정확히 3인 시설의 이름을 모두 적으세요.

**문제 6.** 서울에 있는 시설 중 위험등급이 4 이상인 시설은 어디입니까?

**문제 7.** 설비 용량이 0인 시설이 있습니까? 있다면 어디입니까?

**문제 8.** 설비 용량이 가장 큰 시설은 어디이며 용량은 얼마입니까? 같은 값인 시설이 둘 이상이면 어떻게 확인합니까?

**문제 9.** 변전소 설비 용량의 합계는 얼마입니까?

**문제 10.** 2020년 이후에 설치된 시설을 찾으세요. "2020년 1월 1일에 설치된 시설"이 있었다면 이 결과에 들어갈지
어떻게 알 수 있습니까?

## 23.2 답 읽기와 근거

**문제 13.** 등급 ② 가 나온 답을 하나 찾아(힌트: "가장 높은 ○ 5개"), **추정** 이 붙은 문장이 왜 추정인지 설명하세요.

**문제 14.** 근거 카드에서 굵은 값과 굵지 않은 값의 차이는 무엇입니까?

## 23.9 풀이

| 번호 | 풀이 |
| --- | --- |
| 1 | `대구에 있는 철탑 목록 보여줘`. 조회 조건 "시설 · 시설 유형 = 철탑 · 소재 지역[지역: 지역명 = 대구]". 2곳: 대구 철탑 11호(F-0011), 대구 철탑 23호(F-0023) |
| 2 | `수원지사가 소유한 변전소는 몇 개야?`. 확인할 조건: ① 시설 유형 = 변전소 ② 소유 조직[조직명 = 수원지사], 끝이 "건수"인지도 확인. 3개 |
| 3 | 조건 셋(설치일 ≥ 2015-01-01, 위험등급 ≥ 4, 시설 유형 = 철탑). 6곳: 부산 철탑 14호, 강남 철탑 17호, 수원 철탑 20호, 대구 철탑 23호, 부산 철탑 26호, 강남 철탑 29호 |
| 4 | 3.1. 근거 칩은 "결과 1"(집계 결과) — 조회 조건이 곧 근거 |
| 5 | 부산 철탑 02호, 대구 전주 27호, 수원 변전소 28호, 부산 전주 30호(4곳) |
| 6 | 강남 전주 09호, 강남 철탑 17호, 강남 변전소 25호, 강남 철탑 29호(4곳) |
| 7 | 있음. 부산 철탑 02호(설비 용량 0) |
| 8 | 3,000kW. 수원 변전소 04호와 대구 변전소 07호가 같은 값. "설비 용량이 3000kW인 시설 목록"으로 다시 물어 모두 확인 |
| 9 | 20,000kW |
| 10 | 부산 철탑 14호(2022), 대구 변전소 19호(2020-11-03), 강남 전주 21호(2024), 강남 철탑 29호(2020-12-07). 조회 조건의 기호를 본다: "≥ 2020-01-01"이면 포함, "> 2020-01-01"이면 제외(「6장 6.6」) |
| 11 | 처음 설치 상태면 "원천 기록 없음(시드·직접 적재)" — 데이터 소스 동기화가 아니라 설치 때 직접 넣은 데이터라는 뜻. 18장 이후면 "시설 원장 DB · public.fac_master · 동기화 실행 #N" |
| 12 | 그 묶음의 값(시설 유형·건수)과 "집계·계산 결과입니다…" 안내. 개수는 여러 대상을 센 계산 결과라 대상 하나의 카드 대신 답을 만들 때의 계산 값을 보여 준다 |
| 13 | "다음과 같습니다" 같은 첫 문장, "1. 2. 3." 같은 순번은 데이터에 글자 그대로 없는 표현이라 추정으로 표시됨 |
| 14 | 굵은 값은 답에 인용된 칸, 굵지 않은 값은 인용되지 않은 칸 |
| 15 | 쓰면 안 됨. 등급 ①은 값이 조회 결과와 맞다는 뜻일 뿐, 조회 조건이 질문과 다르면 다른 것을 센 답이다 |
| 16 | 1) (첫 목록, 8건) 2) "직전 결과 8건 중" 3) "시설 ID ∈ {…}" 로 2)의 철탑들을 가리킴(N 대신 식별자 목록) |
| 17 | "조회 실패 · 질문 해석 실패". 처음부터 조건을 모두 적어 묻는다: `부산지사가 소유한 시설 중 위험등급이 4 이상인 것` |
| 18 | 가장 최근의 **목록** 결과(합계 바로 앞의 목록) |
| 19 | 조회 실패 · 질문 해석 실패. 데이터에 점검 담당자 정보가 없어서 — 지어내지 않는다 |
| 20 | 경남: 결과 0건(경남에 시설이 없음 = "없다"). 제주 변전소 99호: 질문 해석 실패(그런 이름의 시설을 찾지 못해 계획을 받아들이지 않음 = 엄밀히 "모른다") |
| 21 | 그 데이터 종류의 **읽기 권한**. 관리자에게 확인 요청 |
| 22 | 된다. 관계가 필요 없는 질문은 정상으로 답한다 |
| 23 | "시설 유형 = 철탑"이 빠짐. 그래서 수원 전주 12호가 섞임. 정답은 수원 철탑 20호 한 곳 |
| 24 | "설치일 ≥ 2015-01-01"이 빠져 2015년 이전도 포함. `2015년 1월 1일부터 2015년 12월 31일까지 설치된 시설` 처럼 범위를 분명히 |
| 25 | ① 대상 이름과 식별자(수원 전주 12호 · F-0012) ② 바뀔 값(지금 4 → 실행 후 3) ③ 알림 받는 사람과 문구 |
| 26 | **막힘**. 강남 전주 21호의 위험등급은 1이라 사전 조건(≥ 3) 실패 |
| 27 | "요청을 그대로 만들 수 없습니다" + 확인할 것 "'새 위험등급' 값이 필요합니다" + 양식. 양식의 새 위험등급에 값을 넣고 **미리보기** |
| 28 | 요청 카드의 **요청 거두기**. "거부" 상태, 거부 사유 "요청자가 거뒀습니다"로 남음 |
| 29 | 확인 창: "실행하면 편집 레이어에 쓰고 알림을 보냅니다. 메일·SMS 는 되돌릴 수 없습니다. 실행할까요?" |
| 30 | ① 바뀐 값이 원래 값으로(편집 해제) ② 아직 안 나간 메일·SMS 취소 ③ 이미 받은 사람에게 정정 알림 |
| 31 | 바뀐 값 아래 **편집됨** 배지, "원천 값 ○", 요청자와 실행 시각 |
| 32 | 모든 조회와 계산이 편집 레이어의 값으로 하기 때문(카드와 계산이 같은 값을 씀) |
| 33 | 답이 모호하다고 판단해서. 구체적인 이름·숫자·예를 들어 답한다 |
| 34 | 데이터로 답할 수 있는 질문이면 **기대 답변** |
| 35 | **거절**. 데이터에 없는 것을 설계도에 넣으면 답할 수 없는 질문만 늘어남 |
| 36 | **수정** → 자료형을 int 등 알맞은 것으로(또는 enum 값 목록을 채움) → **수정 확정** |
| 37 | 버전 목록에서 게시된 버전의 **이 버전으로 새 draft** |
