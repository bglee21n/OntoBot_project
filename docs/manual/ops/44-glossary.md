# 44장 용어집

가나다순입니다. 영문 용어는 우리말 풀이와 함께 적었습니다. 자세한 설명은 3장과 괄호 안의 장을 보세요.

| 용어 | 뜻 |
| --- | --- |
| 감사 로그 | 누가 언제 무엇을 했는지의 기록. 지우거나 고칠 수 없음(9장) |
| 객체 | 객체 타입의 실제 한 건(예: 강남 변전소 01호) |
| 객체 타입 | 대상의 종류(예: 시설). 읽기 권한의 단위(8장) |
| 게시 | 온톨로지 초안을 확정해 쓰게 하는 일. 게시본은 고칠 수 없음 |
| 게시본 | 지금 쓰는 온톨로지 버전. 하나뿐 |
| 근거(인용) | 답 문장이 기댄 데이터. `[[o:Facility/F-0002#risk_grade]]` 꼴 |
| 근거 카드 | 근거 단추를 누르면 나오는 객체 정보와 값 출처 |
| 그래프 투영 | PostgreSQL 의 관계를 Neo4j 에 옮겨 적는 일(13장) |
| 대사 | 두 저장소의 내용이 같은지 비교하는 일(13.2) |
| 데이터 소스 | 원천 DB 하나의 접속 정보 묶음(11장) |
| 동기화 | 원천에서 OntoBot 으로 데이터를 읽어 복사하는 일(12장) |
| 등급 ①②③ | 답 문장이 근거와 맞는 정도(근거 확인 / 일부 추정 / 근거 부족) |
| 롤백(Action) | 실행된 Action 을 되돌림(14.6) |
| 롤백(배포) | 업그레이드를 되돌림. 프로그램만 / DB 까지(22장) |
| 링크 | 객체 사이의 관계(예: 시설 → 소유 조직) |
| 마스킹 | 개인정보를 가려 보이는 것 |
| 마이그레이션 | 새 버전에 맞게 데이터베이스 구조를 고치는 일 |
| 매핑 | 원천 표의 열을 속성에 짝지은 것(12장) |
| 미리보기 | Action 실행 전 바뀔 값·알림을 보여 주는 단계. 곧 요청이 됨 |
| 반입 폴더 | 새 번들을 복사해 두는 서버 폴더 `C:\OntoBot-bundles`(20.3) |
| 반영 | 설정을 바꾼 뒤 컨테이너가 새 설정을 읽게 하는 것 |
| 발송 | 메일·SMS 한 통. 대기 / 보냄 / 실패 / 취소(15장) |
| 배포 콘솔 | 업그레이드·롤백·백업을 하는 관리자 화면(8100, 17장) |
| 번들 | 설치·업그레이드 꾸러미. 전체 / 앱만(4장, 20장) |
| 볼륨 | 컨테이너가 지워져도 남는 데이터 공간 |
| 사전 점검 | 업그레이드 전에 바꾸지 않고 확인하는 일(20.2) |
| 서명 / 공개키 / 개인키 | 번들이 진짜인지 확인하는 장치(4.4) |
| 세션 | 로그인이 유지되는 동안. 기본 8시간 |
| 속성 | 객체가 가진 정보 한 칸 |
| 시크릿 참조 | 비밀번호가 있는 곳을 가리키는 글자(`env:PREFIX`, `file:경로`) |
| 알림함 | 화면 안 알림(Action 메뉴의 빨간 숫자) |
| 앞머리(PREFIX) | `app.env` 의 접속 정보 다섯 줄의 공통 이름(11.2) |
| 업그레이드 | 새 버전으로 올리는 일(21장) |
| 역할 | 할 수 있는 일의 묶음(user·modeler·bot_builder·domain_expert·admin) |
| 원천 | 원래 데이터가 있는 사내 DB 와 그 표 |
| 읽기 권한 | 역할마다 읽을 수 있는 객체 타입(8장) |
| 워커(worker) | 동기화·투영·발송·정리를 하는 뒤쪽 프로그램 |
| 워터마크 열 | 증분 동기화에서 바뀐 행을 알아보는 열 |
| 이미지 | 프로그램과 실행 환경을 묶은 것 |
| 작업 기록 | 배포 콘솔이 한 일의 기록과 출력(24장) |
| 재구축 | Neo4j 를 처음부터 다시 만드는 일(13.5) |
| 전체 모드 / 증분 모드 | 매번 표 전체를 읽기 / 바뀐 행만 읽기(12.2) |
| 정정 문구 | 롤백 때 이미 알림을 받은 사람에게 보내는 취소 안내 |
| 조회 계획(plan) | AI 가 질문을 바꾼 조회 조건(10장) |
| 조회 조건 문장 | 답 위에 보이는 회색 줄. 질문을 어떻게 이해했는지 |
| 준비 상태(`/readyz`) | 데이터베이스·관계 저장소·AI 모델에 닿는지(18.2) |
| 지금 백업 | 배포 콘솔의 즉시 백업 단추(19.2) |
| 컨테이너 | 실행 중인 프로그램 하나 |
| 트레이스 | 질문 한 건의 처리 기록(10장) |
| 편집 레이어 | Action 으로 바꾼 값을 원천과 따로 보관하는 곳 |
| 편집 충돌 | 편집 뒤 원천 값도 바뀐 경우(16장) |
| 폐쇄망 | 인터넷이 끊긴 사내망 |
| 현황 | 배포 콘솔의 첫 화면(18장) |
| Action | 데이터를 바꾸는 요청(14장) |
| admin | 관리자 역할. 배포 콘솔 로그인에 필요 |
| api | 웹 화면과 API 를 맡는 컨테이너(8000) |
| `app.env` | 앱 설정 파일(30.2) |
| compose(docker compose) | 컨테이너 여러 개를 한 번에 다루는 도구 |
| degraded(일부 저하) | Neo4j 만 안 되는 준비 상태 |
| deployer | 배포 콘솔 컨테이너 |
| `-dirty` | 개발 중 번들 표시. 운영에서 거부 |
| Docker | 컨테이너 실행기 |
| `.env` | 인프라 설정 파일(30.3) |
| GPU | AI 모델을 빠르게 돌리는 그래픽 처리 장치 |
| `/healthz` | 프로그램이 살아 있는지만 보는 확인 |
| migrate | 데이터베이스 구조를 맞추고 끝나는 일회성 컨테이너 |
| Neo4j | 관계(링크)를 빠르게 찾는 그래프 저장소. 복사본 |
| OIDC(SSO) | 회사 통합 로그인 방식 |
| Ollama | 서버 안에서 AI 모델을 돌리는 프로그램 |
| `ontobotctl` | 설치·업그레이드·롤백·백업 절차 명령(29.2) |
| pk | 객체를 하나로 가리키는 값 |
| PostgreSQL | 모든 기록의 원본 데이터베이스 |
| RESTORE | DB 까지 복원 롤백의 확인 글자(22.5) |
| SHA256SUMS | 번들 파일의 지문 목록 |
| `state.env` | 설치 상태 파일(지금·이전 버전, 마지막 백업) |
| unavailable(사용 불가) | 데이터베이스나 AI 모델이 안 되는 준비 상태 |
| UTC | 세계 표준시. 한국 시각 = UTC + 9시간 |
| WSL2 | 윈도 안에서 리눅스를 돌리는 기능 |
