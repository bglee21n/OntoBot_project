# 41장 화면·명령 문구 사전

사용자나 화면이 보여 주는 문구를 그대로 찾아 뜻과 할 일을 확인하는 사전입니다. 문구는 프로그램의 원본에서 옮겼고,
이 책에서 실제로 본 것에는 장 번호를 붙였습니다. 문구 안의 `…` 는 상황마다 바뀌는 값입니다.
